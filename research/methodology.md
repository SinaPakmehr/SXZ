# Methodology and result schemas

Use the same bytes, decoder checks and backend for attribution. Where a format
is first exposed, retain reconstruction metadata and compare the same exposed
representation without the mathematical step. For a mosaic that changes
backend context, hold the boundaries and remaining literal stream constant
and substitute the exact matched bytes for the model reference.

Archive length includes framing, controls, parameters, offsets, residuals,
literal payload, checksums and necessary dictionaries. The raw union of match
intervals is not economic coverage. Local scores need not be additive after a
context-sensitive backend. Highlight absolute sizes and paired differences before
interpreting aggregate ratios. Use held-out inputs for decision rules.

`lab/*/results/` contains phase-local historical schemas. A JSON may be an
array of records, `{rows: [...]}`, or a set of named experiment blocks.
`bytes` denotes byte count at the scope of its record, not always input size;
`input_bytes`, `file_bytes`, `n` and input manifests supply denominators.
`encode_s` and `decode_s` are seconds; `MB/s` denotes decimal throughput when
explicitly reported. Keep seed trials as rows, not independent files.
Encoded offsets, symbols and bytes must not be combined without conversion.

Unless specifically labeled in the validation guide, the records are historical
and are not a new independent run. Removed machine/environment strings and
relative path changes are publication redactions, not edits to timings or scores.
Generated figures and the evidence table are *derived* from those records.
