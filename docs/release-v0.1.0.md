# SXZ v0.1.0 — Initial Public Research Release

## Release description

The initial public release of SXZ, an experimental research framework exploring
mathematical and generative approaches to lossless data compression.

This release documents ten research phases, including mathematical pattern
detection, algebraic inference, program synthesis, structural relationships,
generative mathematical dictionaries, and adaptive pseudorandom sequence
mosaics.

It includes experimental source code, benchmark results, research protocols,
mathematical analysis, reproducibility instructions, and both positive and
negative findings.

SXZ is experimental. Meaningful and reproducible independent compression
improvements on general-purpose files have not yet been demonstrated.

The project welcomes independent replication, mathematical criticism, new
hypotheses, and collaborative research.
