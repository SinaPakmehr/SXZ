# Contributing

SXZ welcomes mathematicians, computer scientists, information-theory
researchers, compression specialists, machine-learning and GPU researchers,
software developers, independent experimentalists, and anyone interested in the
underlying mathematical questions.

Contributions may include new hypotheses, alternative generative
representations, number-theoretic or algebraic approaches, program synthesis,
information-theoretic analysis, independent replication, benchmarks, bug fixes,
and rigorous criticism. Mathematical counterarguments, theoretical limits and
negative experimental results are first-class contributions.

## Evidence standard

State what would falsify a hypothesis before testing it. Identify the paired
baseline, codec and representation settings, search budget, data-rights status,
checksum, units, archive overhead, and byte-for-byte round-trip method. Separate
empirical findings from conjectures, report negative runs, and never substitute
a different input while calling it a replication. Do not rewrite historical JSON
in place; append a new run or an explicit erratum.

For performance reports, state software versions and non-identifying timing
conditions. Do not share personal inputs, credentials, local paths, or host
details. A contribution must not require contributors to disclose personal
information.

## Collaboration spaces

When the repository's community features are enabled, the intended discussion
categories are: General Discussion, Mathematical Hypotheses, Research Ideas,
Experimental Results, Machine Learning and GPU Computing, Reproduction and
Validation, Theoretical Criticism, and Questions and Answers.

Issue templates are provided for research hypotheses, mathematical analysis,
experiment proposals, reproduction reports, benchmark contributions, bug
reports, and performance improvements. Pull requests should include the smallest
reproduction, tests run, scientific or engineering contribution, and privacy
review.
