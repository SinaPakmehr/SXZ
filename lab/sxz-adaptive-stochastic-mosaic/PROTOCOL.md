# ASMC measurement and stop rule (frozen before the test panel)

- Main units are complete files, byte stream, no format parsing. Reuse the
  prior 19-file byte-panel, plus independent-source originals; three old dev
  items only for exploration. Reuse fixed MSMC raw results read-only.
- Exhaust 8/12/16-bit seed spaces at 96 bytes per seed. Above 16 use a fixed
  65,536-seed permutation subset at 20/24/32 bits, not a full enumeration.
  On the exhaustive dev curve use one counter generator; at the frozen test
  setting use 12 bits (393,216 generated bytes per bank). Match baseline banks
  by total positions and per-record wire accounting. Adjust any quota only in
  an explicitly separate diagnostic.
- Three-byte anchors, up to six addresses per duplicate key, verify/extend
  every retained exact candidate. Exact byte gain is measured for independent
  seed (A), one common seed (B), up to four common seeds (C). Cap emitted
  candidates per target and disclose saturation. DP is over observed intervals;
  group-set selection is bounded, not a claim of a global optimum.
- Compare to direct storage, fixed seed bank, independent uniform counter bank,
  histogram-trained and target-fitted stochastic banks, static entropy codes,
  repeat-only, external trained dictionary and MSMC. For every positive whole
  file use the identical segmentation and Zstd literal stream with the matched
  pieces stored as literals, not seed references.
- Continue only for >=1% and >=128 B measured gain over both direct and matched
  segmentation, with evidence against matched controls on at least three
  independently sourced, held-out whole files. Otherwise no massive seed
  sweep, no industrial or 1/10/100-MB scaling claim, and no new product.
- After exact results, run a separate limited approximate/residual ablation.
- Decoder: fixed opcodes and catalog only, 128 MiB output, bounded instruction
  count, per-source extent and total regenerated bytes; no code from a stream.
