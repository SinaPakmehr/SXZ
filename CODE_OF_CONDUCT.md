# Research conduct

Discuss evidence and methods, not people. Treat criticism, replication and null
results as contributions. Harassment, discrimination, and disclosure of personal
information are unacceptable.

A dedicated confidential Code of Conduct reporting channel has not yet been
added. For a confidential conduct report, use the repository's private GitHub
reporting interface at
<https://github.com/SinaPakmehr/SXZ/security/advisories/new> and mark the report
as a Code of Conduct concern; do not post identifying details publicly. This is
an interim private intake route, not a dedicated conduct inbox; the maintainer
must confirm it after enabling the feature.
